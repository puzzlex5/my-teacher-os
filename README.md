# MY TEACHER OS

개인 교사를 중심으로 학년도별 수업·평가·행정업무·업무기억을 누적하는 개인용 Teacher OS입니다.

## v0.1 원칙
- 학교급을 고정하지 않음: 중학교/고등학교/기타 환경을 학년도별로 설정
- 평가계획서는 해당 학년도에 연결
- 행정업무는 고정 메뉴가 아니라 그해 업무를 프로젝트처럼 추가
- 같은 업무를 여러 해 맡으면 업무기억을 누적
- 실제 학교 문서와 개인정보는 공개 GitHub 저장소에 저장하지 않고 브라우저 로컬 저장소를 우선 사용

## 다음 단계
1. 평가계획서 PDF/HWP 분석
2. 평가 항목·반영비율·시기·성취기준 자동 구조화 후 사용자 승인
3. 전년도 반복 행정업무 복제
4. 학사일정·시간표 연결
5. AI Agent 서버 계층 연결

사이트 코드는 `index.html`에서 실행합니다.
